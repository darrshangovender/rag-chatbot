# Pricing Plans

Cumulus has four plans. All prices are per user per month, billed annually. Monthly billing is available at a 20% premium.

## Free

Up to 10 users, 3 active projects, 14-day activity history. Includes core task tracking, sprints, and the mobile app. No SSO, no audit log, no API access.

## Starter — $8 / user / month

Unlimited projects, 1-year history, all standard integrations (GitHub, Slack, Google Drive, Figma). Includes the public REST API with a 60-requests-per-minute rate limit. No SSO.

## Business — $16 / user / month

Adds SAML SSO, SCIM provisioning, custom fields, sprint analytics, and a 600 RPM API rate limit. Standard support: email response within one business day.

## Enterprise — contact sales

Adds audit log export, data residency choice (US, EU, or AU), customer-managed encryption keys (CMEK), private workspace networking via AWS PrivateLink, and a named customer-success contact. SLA: 99.95% uptime, 4-hour P1 response. Minimum 50 users.

## Plan changes

You can upgrade at any time — the new price is pro-rated to the day. Downgrades take effect at the end of the current billing period; you keep the higher plan until then. Cancellations are processed through **Settings → Billing → Cancel plan** and require admin role.
