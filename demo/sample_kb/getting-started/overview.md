# Cumulus Overview

Cumulus is a project-management tool for distributed product teams. It combines task tracking, sprint planning, and lightweight documentation in a single workspace, so engineering and product don't have to context-switch between five different SaaS apps.

## Who uses Cumulus

Cumulus is built for teams of 5 to 200 people. Below that, a shared spreadsheet is usually enough. Above that, our roadmap features start to creak — we recommend an enterprise PPM tool instead.

## Core concepts

- **Workspace** — your company's top-level container. One workspace per company.
- **Project** — a body of work with a defined goal. Maps to a team or a product surface.
- **Task** — the unit of work. Has a status, assignee, due date, and parent project.
- **Sprint** — a time-boxed batch of tasks, typically 1-2 weeks.

## What Cumulus is not

Cumulus is not a CRM, a help desk, or a code repository. We integrate with Salesforce, Zendesk, and GitHub, but we don't replace them.
